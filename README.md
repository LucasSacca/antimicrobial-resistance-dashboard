# 🦠 Antimicrobial Resistance Monitoring Dashboard

## 📌 Project Overview

This project was developed as part of a **Biomedical Engineering elective course** and aims to design and implement a monitoring system for antimicrobial resistance (AMR).

The solution consists of an interactive dashboard built with **Streamlit**, allowing visualization and analysis of microbial resistance patterns based on structured data.

---

## 🎯 Objective

To develop an end-to-end system for monitoring antimicrobial resistance, including:

* Data processing from CSV files
* Visualization of resistance patterns
* Interactive exploration through a web-based dashboard

---

## 📊 Data Source

The dashboard uses structured data from a CSV file:

* `sample_data_clean.csv`

The dataset contains information related to:

* Microorganisms
* Antibiotics
* Resistance profiles
* Additional clinical or laboratory variables

---

## ⚙️ Technologies Used

* **Python**
* **Streamlit**
* **Pandas**

---

## 📈 Features

* Interactive filtering of data
* Visualization of resistance patterns
* Comparative analysis between microorganisms and antibiotics
* User-friendly interface for exploratory analysis

---

## 🧠 Use Cases

* Epidemiological monitoring
* Hospital infection control support
* Academic and educational purposes
* Data-driven decision-making in antimicrobial therapy

---

## ⚠️ Disclaimer

This project is intended for **educational purposes only** and should not be used as a sole basis for clinical decisions.
